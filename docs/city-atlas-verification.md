# 城市图鉴验证记录

本轮新增 15 城、90 景点，连同原有北京与罗马合计 17 城、110 景点。

## 已验证

- Python 测试 20 项通过。其中静态测试遍历全部 15 个新城市入口、90 个景点页及其资源，检查阅读区、默认放大镜状态、独立热点坐标、三节文章和前端注册信息；部署测试分别验证本地复制、云端移动，确认图片字节不变、元数据留在后端、环境配置不会公开。
- 120 张新增图片逐一通过 Pillow 完整性校验。
- 15 座新增城市均在隔离浏览器走通：城市封面 → 长卷 → 最后一个景点 → 默认鼠标放大镜 → 第一个热点说明 → 关闭 → 下方讲解 → 返回并恢复选中景点。
- 城市目录的中文/英文搜索与卡片跳转已验证；首页城市入口可见。
- `/?fly=berlin` 从地球点亮并进入柏林名片已验证。
- 广州长卷的鼠标拖动、键盘景点切换与滚动条 Home 复位已验证。
- 390 × 844 宽度下抽测目录、搜索、新加坡名片、景点点击、文章跳转，无横向溢出。
- 北京旧图鉴在全新浏览器中渲染阅读区，无 React 页面错误；服务端阅读 HTML 与客户端组件保持一致。

## 边界

- 90 个新景点全部覆盖静态检查，交互测试按每城一个景点抽测；共用同一图鉴交互实现。
- 本轮未重新发起付费聊天、语音或用户个性化生图调用；这些服务未做逻辑改动。
- 机票入口校验链接参数，不执行出票、购买或支付；未逐城验证 Trip 页面目的地自动填充。
- 北京、罗马原图鉴保留原有大屏体验限制；新增图鉴及城市目录支持窄屏阅读。
